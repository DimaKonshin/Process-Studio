# Workflow Designer

- `WorkflowCanvasState` принадлежит экземпляру редактора. Компонент передаёт ему действия через `moveNodes` и `connect`. Идентификаторы шагов и портов должны оставаться стабильными. Стрелка ссылается на ID портов, а позиция шага хранится в координатах схемы.
- При изменении холста сверяем директивы и события с `node_modules/@foblex/flow/AI.md` в корне репозитория. Настройки темы описаны в `node_modules/@foblex/flow/STYLING.md`.
- В браузере проверяем жест целиком. Например, проводим стрелку между портами, двигаем соединённый блок и проверяем оба конца стрелки. Для изменений сохранения повторяем сценарий после перезагрузки страницы.
- Библиотеку собираем командой `ng build workflow-designer`, приложение с её публичным API — командой `ng build workflow-editor`.
